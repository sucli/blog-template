# Security Policy

## Supported versions

This repository is a template. The latest commit on `main` is the only version receiving fixes.

| Version | Supported |
| --- | --- |
| `main` | ✅ |
| forks / older tags | ❌ |

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

1. Prefer GitHub's private reporting: [Security → Report a vulnerability](https://github.com/sucli/blog-template/security/advisories/new)
2. Or email the maintainer listed in `site.config.json` / the repository profile

Include:

- A short description of the issue
- Steps to reproduce or a proof of concept
- Impact assessment if known
- Any suggested fix

You should receive an acknowledgement within a few days. Once fixed, credit will be given unless you prefer to remain anonymous.
